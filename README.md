# Computer Vision Systems – Lab Exercises (AGH AiR, 2nd Year)

This repository contains my lab work from the course **Systemy Wizyjne (Computer Vision Systems)** during the second year of Automation and Robotics at AGH University of Science and Technology.

The labs focus on the fundamentals of **digital image processing**, including point operations, histograms, thresholding, and interpolation techniques. Tasks were completed using **MATLAB** and **Python (Jupyter Notebooks)**.

---

## 🧪 Lab Overview

| Lab | Topic | Description |
|-----|-------|-------------|
| `01_intro/` | Introduction | Environment setup and basic image visualization |
| `02_point/` | Point operations | Brightness, contrast adjustment, and grayscale conversion |
| `03_histogram/` | Histogram equalization | Histogram plotting, stretching and equalization |
| `04_thresholding/` | Thresholding | Global and adaptive methods: Otsu, Sauvola, etc. |
| `05_resolution/` | Image resolution | Scaling, downsampling, and interpolation methods |
| `06_context/` | Contextual filtering | Convolution, edge detection, and smoothing filters |
